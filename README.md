# Freelance Financial Tracker

A Google Sheets-based financial management system designed for Italian freelancers with a **Partita IVA** and **INPS Gestione Separata**.

The tracker combines financial monitoring, tax and contribution planning, forecasting, and automated workflows in a single system.

> **Note:** The current setup is designed around the Italian freelance tax system, but its parameters and workflows can be adapted to different tax regimes and freelance setups.

## Key Features

- Income and expense tracking
- Invoice management
- Tax and INPS contribution planning
- Financial reserve monitoring
- Monthly and annual financial summaries
- Financial forecasting
- Automated Google Apps Script workflows
- Dashboard for financial KPIs
