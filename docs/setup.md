# Setup Guide

## Requirements

To use the Freelance Financial Tracker, you need:

- A Google account
- Google Sheets
- Access to Google Apps Script

## Getting Started

1. Create your own copy of the Financial Tracker in Google Sheets.
2. Review the configuration options in the `Settings` sheet.
3. Customize the available categories, subcategories, accounts, payment methods, services, and channels.
4. Review the tax and contribution parameters according to your freelance setup.
5. Open **Extensions → Apps Script** in Google Sheets.
6. Add the automation script provided in the `scripts` directory of this repository.
7. Save the Apps Script project.
8. Configure any required triggers.
9. Test the tracker with sample data before using it with real financial information.

## Important

The tracker was originally designed for Italian freelancers with a Partita IVA and INPS Gestione Separata.

Tax rates, contribution rates, reserve calculations, and other financial parameters should be reviewed and adapted to the user's individual tax situation.

The tracker is a financial organization and planning tool and does not replace professional tax or accounting advice.
